# MyFirstProjectPython2223

## Описание

Программа для учёта интернет-магазина.

Приложение позволяет:

- добавлять клиентов;
- добавлять товары;
- создавать заказы;
- просматривать заказы;
- выполнять поиск клиентов;
- анализировать данные о заказах;
- определять топ клиентов;
- смотреть динамику заказов по датам.

## Технологии

- Python
- Tkinter
- SQLite
- pandas
- matplotlib
- seaborn
- networkx

## Структура проекта

- `main.py` — запуск приложения
- `gui.py` — графический интерфейс
- `db.py` — работа с базой данных SQLite
- `models.py` — модели данных
- `analysis.py` — анализ заказов
- `shop.db` — база данных
